Download **Horizon-Offline.exe** below and open it on Windows x64.

On first launch, let Horizon install its game build, then press **Play**. It downloads the pinned Minecraft files and the required Java runtime directly from Mojang, verifies their checksums and prepares the resources locally. You do not need to install Java, Python, Rust or another launcher.

After preparation, single-player works without Microsoft sign-in or an internet connection. Pick a name in Settings → Account to keep a local profile. Online-mode servers still require a valid Microsoft account.

The first setup requires internet access. Game files and prepared Minecraft resources are not included in this executable or this release. This distribution uses the signed Horizon game builds from [horizon-rust/horizon](https://github.com/horizon-rust/horizon).

Скачайте **Horizon-Offline.exe** и откройте его. Дождитесь установки сборки игры и нажмите **Играть**: нужные файлы и Java загрузятся и подготовятся автоматически. После подготовки можно играть в одиночную игру офлайн, без входа в Microsoft.
